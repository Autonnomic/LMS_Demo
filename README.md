## 🎓 For Students: Learning Made Easy

### Intuitive Course Management
- **Interface** — Familiar, modern design that feels natural
- **Course Overview** — See all your enrolled courses at a glance with beautiful course cards
- **Detailed Course Pages** — Access schedules, enrolled classmates, and professor information instantly
- **Smart Navigation** — Easy sidebar navigation to jump between courses and sections

### Stay Organized
- **Class Schedules** — View semester-wise schedules for each course
- **Upcoming Topics** — Know what's coming next in your courses
- **Course Information** — Quick access to course codes, credits, and descriptions

### Seamless Experience
- **One-Click Access** — Navigate to any course detail page instantly
- **Visual Course Identification** — Each course has its own color scheme for easy recognition
- **Responsive Design** — Access your courses from any device

### Powerful Course Management
- **Dashboard Overview** — See all your courses and enrollment counts at once

- **Student Management** — View enrolled students and add new ones easily

- **Quick Attendance** — Mark attendance for all students in one go

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ installed
- Supabase project set up
- Environment variables configured

### Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to get started.
